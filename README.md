# 试卷识别

> 一个 macOS 本地 App：把整份试卷的图片或 PDF 识别成一份可编辑的 Word 试卷，点一下就好。
>
> 不用碰命令行，不用另外装东西，打开就能用。

---

## 它是干什么的

老师手里是一套拍好的试卷照片（或者学校发的 PDF），想把它们变成一份能改、能印的 Word 文档。

这个 App 就是把这件事做完：

1. 把整份试卷的图片（可多选）或一个 PDF 放进上传框，点「开始识别」
2. App 在内置浏览器里登录 DeepSeek，按既定的《试卷识别规则》，让 AI 写出生成试卷的 Python 脚本
3. App 用自带的 Python 运行这段脚本，产出排版好的试卷 docx
4. 生成完成后，在 Word 卡里点「下载 Word 试卷」，存到你想放的地方

同一批图如果其实是**学生手写作文**（手写占全图文字一半以上），App 会让 AI 自动改走另一套转录规则，
把作文一篇一页整理成合辑 —— 不用你另外换个工具。

## 基本功能

| 功能 | 说明 |
| --- | --- |
| 批量上传 | 一次可选最多 48 张 png / jpg，或者 1 个 PDF；两类不能混放。也可以 ⌘V 粘贴（支持一次粘多张图） |
| 按规则识别 | 内置识别与排版规则：按卷面大标题自动排页序、去重叠、去水印/状态栏、逐字保真 |
| 手写作文转录 | 同一批图若是学生手写作文，自动切到转录规则：一篇一页、照原样转录不纠错、按统计在左上角加学生标识 |
| 插图占位 | 原卷里的图、表用「1 行 1 列表格」模拟，紫字标注，尺寸按原图比例估 |
| 版式硬指标 | A4、四边 2.2 cm、装订线 0、中文宋体、英文 Times New Roman、红色答案还原为红色 |
| 内置 DeepSeek 浏览器 | 不用开 Safari，不用给 Apple 事件授权；登录一次后会话保存在 App 自己的容器里 |
| 浏览器全程隐形 | 生成时浏览器不露面，只有登录时才显示一次，登录成功 5 秒后自动收起 |
| 自动等、自动续 | 每 5 秒播报一次进度和代码字数；AI 写到一半停了，会自动点「继续生成」续上；整轮上限 10 分钟 |
| 下载 Word 试卷 | 生成完成后在 Word 卡下载 docx，下载成功后临时文件自动清理 |
| 运行日志 | Word 卡右上角「详情」随时看这次运行的完整日志，**成功失败都只有这一个入口** |

## 上传框长什么样

```
+---------------------------------------------------------------+
  +----+ 上传试卷  ✓          按 ⌘V 粘贴，点框外取消
  | +  | 整份试卷：多张图片可一次选完，或一个 PDF，图片最多 48 张
  +----+
  [ ] [ ] [ ] [ ] [ ] [ ]   ← 一行 6 个
  [ ] [ ] [ ] [ ] [ ] [ ]   ← 固定两行，多的框内滚动
+---------------------------------------------------------------+
```

- 卡片左下角是序号，**这是送给 AI 的顺序**，不代表卷面顺序（AI 会按大标题自己排）；文件名鼠标停一下能看到
- 点卡片放大看大图；点右上角小圆叉单独移除
- 固定露两行（12 个），超过 12 张时框内出现滚动条；卡片高度始终不变，不会把窗口撑开
- **固定 6 栏，不随文件数变**：空位用虚框补齐，只放 1 个也是 6 栏的格子，不会整行铺开

## 从源码构建

```bash
cd ocr-exam-app
./build.sh              # 只构建到 dist/试卷识别.app
./build.sh --install    # 构建 + 覆盖安装到 /Applications + 启动
```

没有 Xcode 工程，纯 `swiftc` 手工组装。产物约 79MB，其中约 75MB 是自带的 Python 3.12 + python-docx 运行时，所以用户机器上不用再装 Python。

三个自检入口：

```bash
"dist/试卷识别.app/Contents/MacOS/ExamOCR" --selftest
"dist/试卷识别.app/Contents/MacOS/ExamOCR" --runpython tools/sample_build.py
"dist/试卷识别.app/Contents/MacOS/ExamOCR" --prompttest     # 打三种附件组合的提示词
```

界面状态可以直接看：`--uidemo`（生成中）/ `--uidemo2`（已出成品）/ `--uidemo3`（失败）/
`--uidemo7`（20 张图撑满网格）/ `--uidemo8`（等待粘贴态）/ `--uidemo9`（大图预览）/ `--logdemo`（日志面板）。

## 需要注意的几点

- **只支持 macOS**，用的是苹果的 SF Symbol、液态玻璃这些系统专属的东西，换平台要重写。
- **要登录 DeepSeek 网页版**，试卷是经由你登录的 DeepSeek 账号识别的；退出账号后会话会被清掉。
- **页数越多越慢**：20 张照片一轮通常 3–8 分钟，AI 会分段输出，中途自动点「继续生成」是正常的。
- **AI 写完的判定偶尔会误判**，这是这类自动化的通病；失败时先点 Word 卡右上角「详情」看日志，再重跑一整轮。
- **不要用 JS 点击去点「继续生成」**，DeepSeek 会检查事件是不是真实的，App 里用的是真实鼠标事件注入，这一点别改回 JS 点击。
