# 图片转 Word 文档（Python 脚本）提取与排版规则

## 一、 运行环境与输出要求
- **依赖库**：仅限使用 Python 自带的库以及 `python-docx`（当前环境为 Python 3.12.15，无其他第三方依赖）。
- **输出形式**：直接提供完整可执行的 Python 代码，无需生成实际文件。
- **执行结果**：代码运行后，需在当前同级目录下自动生成完整的 Word（`.docx`）文档。

## 二、 图像与内容处理规则
- **去噪**：必须忽略图片中无用的部分，如：水印、手机/平板软件的操作界面（如顶部状态栏、返回按钮、小红书号等）。
- **排序与拼接**：图片顺序可能混乱。**首要排序依据是卷面的大标题结构（如：罗马数字 I, II, III；中文数字 一、二、三；或阿拉伯数字 1. 2. 3. 等）**，辅以上下文语义理解，智能整理出正确的逻辑顺序（如：听力 -> 语法 -> 阅读 -> 写作）。
- **去重与补全**：识别图片间的重叠部分，避免在 Word 内重复输出；对于缺失的极小部分（断页导致的解析部分缺失不受下方**绝对保真**规则的约束），需利用语义智能补齐 —— **补的是解析还是本体，界限见下方两条「残缺处理」，以那两条为准**。
- **【最高优先级】绝对保真**：**严禁自作主张删除图片内的任何文字内容（操作界面文字和明显是截图时重复的部分不受此规则限制）**。必须逐字逐句完整提取，包括所有的解析、冗长的文本、甚至两个版本的范文答案。不得为了排版清爽而概括或省略任何细节。
  - **逐字转录，不做校对**：只要原图文字清晰，就照原样录入。**不要修正任何错别字**（原文写错的字、用错的标点、明显的笔误，一律照抄），**不要调整语序**，**不要重排题目或选项**（原题号是 3、4、5 就写 3、4、5，不要改成 1、2、3；A/B/C/D 选项的顺序也照原样，不要按内容重新排）。
- **残缺处理之一：解析部分允许智能补全**。拼接错位或图片特别模糊，导致某段文字只能看见半行、字体被截断时，先判断它属于哪一部分：
  - 属于**试卷本体**（题干、选项、原文、听力材料、作文要求等）→ **不许猜**，按下面「缺页占位」那条处理。
  - 属于**解析、答案、范文**这类参考性内容 → 允许依据上下文语义**补全成通顺完整的一两句话**，不必保留截断的痕迹，也不必标注哪里补过。
- **残缺处理之二：缺页用标记占位**。试卷可能不完整 —— 开头少几页、中间断了几页、或者结尾缺页。凡是能判断出「这里本该还有内容、但图里没有」的位置，**不要凭想象补写正文**，而是插入一个占位标记：

  - **文字**：`此处可能缺页`（六个字，不要加别的说明）
  - **字体**：**蓝色**（`#0000FF`），**三号**（16pt）
  - **实现方式**：和下面的「插图占位」一样，用 **1 行 1 列表格**模拟文本框，但边框必须是**黑色单线**（`python-docx` 默认表格无边框，需显式加 `single`、8 号、黑色）。
  - **宽度**：页面去掉左右页边距后可用宽度的 **80% 左右**。按本文档页边距 2.2cm、A4 宽 21cm 算，可用宽度 16.6cm，即**约 13.3cm**。
  - **高度**：**不要写死**。用段落间距实现「框内文字上下各留一行高」——即该段落的段前、段后间距各设为约一个字高（三号 16pt 约 18pt），表格高度由内容自动撑开。**不要用 `trHeight exact`**（那是插图占位框的写法，这里是自动高度）。
  - **位置**：表格在页面水平居中。
  - **判断依据**：页码跳号、大题编号断开（如从「二」直接跳到「四」）、上下句明显接不上、图片边缘出现半截题号或半行字、某道题的选项只出现 A、B 就断了等。
- **插图占位处理（高保真模拟）**：如果图片中明显包含插图（图片、图表等），因 Python 无法直接提取原图，需在 Word 内模拟该插图。
  - **最优实现方案**：由于 `python-docx` 原生不支持直接创建文本框，且底层 XML 拼装极易引发兼容性问题，**必须采用“1行1列的表格”来模拟插图框**。
  - **比例与尺寸**：代码需根据原图大致的高宽比（不必绝对精确，如 2:1 的横图或 1:1 的方图），强制锁定表格的**列宽**（如 14cm）和**行高**（通过底层 XML 设置 `trHeight exact`，如 7.5cm）。整个表格需在页面居中。
  - **框内文字**：文字在单元格内需**水平且垂直居中**。使用固定紫色字体（色码：**`#800080`**）。
  - **文字内容**：示例格式为“此处原为插图：插图内容为....”，要求高度精炼不啰嗦，**最多 30 个中文字**。

## 三、 字体与样式规则
- **中文字体**：一律使用 **宋体**（包括全角符号，如圈码数字等）。
- **英/数字体**：一律使用 **Times New Roman**。
- **字重与颜色**：是否加粗需根据图片原版样式尽量保持一致；原图中的红色解析、答案文字需尽量还原为红色；插图占位描述文字强制为紫色（`#800080`）。
- **段前缩进**：原始图片中若有明显段首缩进（如英文文章每段开头空两格），在 Word 中必须保留。实现方式为**增加空格**（建议使用全角空格 `　　` 或固定数量的半角空格），且整个 Word 文档的缩进大小需保持绝对统一。

## 四、 排版与版面规则
- **整体版式**：尽量接近原图，但无需 100% 完美复刻排版边距。
- **试卷专用元素**：**绝对保留**原版中的填空下划线（如 `__1__`）、括号选项、表格结构等试卷专用内容。
- **空行控制**：
  - **大题之间**：必须有明显的空行分隔。
  - **题目内部**：尽量不设空行，保持紧凑（空行的定义：一个回车符或换行符单独占一整行，不可滥用）。

## 五、 页面设置规则（硬性规定）
- **页边距**：强制设置 Word 的上、下、左、右页边距各为 **2.2 cm**。
- **装订线**：强制设置装订线为 **0 cm**。
