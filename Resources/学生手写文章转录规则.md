# 学生手写文章转录规则（Python 脚本）

## 一、适用范围

- 本规则只在「这批图的主体是**学生手写文章**」时使用。
- 判断标准：**手写字符占全图文字的一半以上（≥ 50%）**。手写体和印刷体差别极大，先数手写，数完过半就直接按本规则走，不用再犹豫。
- 不满足这条 → 走《试卷识别规则.md》，本文件不适用。
- Python 环境、输出形式（直接给完整可执行脚本，不生成实际文件）、执行结果（同级目录生成 `.docx`）**同《试卷识别规则.md》第一条**，这里不重复。

### 字符怎么数（硬性）

- 一个英文字母 = **1** 个字符；一个中文字（含全角标点）= **2** 个字符。
- **不算**：空格、空行、扫描重影导致的重复字、手机状态栏、软件界面栏、返回按钮、水印、页码、边框线。
- 分别数出「手写字符」和「印刷字符」，**手写 ÷（手写 + 印刷）≥ 50%** → 走本规则。
- 一批里混着印刷试卷也不要紧：先数手写，过半就走本规则，剩下的印刷内容当背景忽略。
- 只传了很少几张图时容易数不准 —— 宁可让使用者重跑一次，也不要硬猜。

## 二、图像的判断与整理

- **方向**：手机拍摄可能横竖颠倒或倾斜。先判断每张图该转多少度才能正常阅读，再转录，不要把倒着的字硬猜。
- **顺序**：按文章的写作顺序排。有页码就按页码；没有页码就按上下文衔接判断。
- **卷内换页**：学生常写到卷子底部后换到另一张纸继续。**先拼合再转录** —— 不要把一篇拆成两篇，也不要把两篇并成一篇。
- **一图多篇 / 一篇多图**：都按上一条处理。判断依据是段落是否接得上、有没有新的开头（如 `Dear ...`、标题行、署名）。
- **一页一篇**：整理完的每一篇，在 Word 里单独占一页。

## 三、转录什么、不转录什么

- **默认只录学生手写的英文正文。**
- **题目的例外**：如果图里除了手写文章，基本只有**一道文章题目**（中英文都算），没有成片的其它印刷题目 —— 那就把题目也转录，放在这篇的最前面，单独成段、居中：
  - 英文题目：**Times New Roman，四号（14pt），加粗**。
  - 中文题目：**宋体，四号（14pt），加粗**。
- **不录**：成片的印刷题目（阅读理解、完形、语法填空等）、中文说明、题号、答题卡边框、页眉页脚、页码、学校 / 班级 / 姓名栏里的印刷字。
- **不录教师批注**：红笔的对勾、叉、分数、等级、评语、圈画、红笔改错，一律不转录。
- **红笔的例外**：学校不允许学生用红笔写文章，所以红笔基本等同于批改。只有一种情况要当正文转录 —— **整篇文章都是红笔写的**（那就是学生用红笔写的，不是批改）。零散的红笔字一律当批注忽略。
- **涂改以最终结果为准**：
  - 修正液、涂改带盖住的 → 不录被盖的内容，只录露出来的。
  - 黑笔 / 铅笔划掉的词句 → 不录被划掉的，只录留下的。
  - 划掉一个词、在旁边重写 → 录重写的那个；整段划掉重写 → 录重写的那段。
- **分段照原样**：原文分了 3 段就 3 段，不要合并也不要拆开。

## 四、拼写与字符（最容易做错的一条）

- **照原样转录，不做纠正**。学生明显拼错的词照抄：`because` 写成 `becase` 就写 `becase`，`there` 写成 `their` 就写 `their`。
- **但只有你真看清了才照抄**。凡是字母形状本身容易混、你自己也拿不准的，一律按**通顺正确的拼写**写，不要为了「忠实」故意写成错字：
  - 大写 `I` 和小写 `l`
  - 字母 `O` 和数字 `0`
  - `rn` 和 `m`、`cl` 和 `d`
  - `1` 和 `l`、`5` 和 `S`、`2` 和 `Z`
- **大小写、标点照原样**：句首学生没大写就保持小写，标点用得不对也照抄。
- **整词都看不清**：不要猜一个「看起来像」的词。按上下文最通顺的常见词写。

## 五、字体与排版

- 字体：**Times New Roman**，**不加粗**（`bold = False`）。
- 字号：**小四**（12pt）。
- 段落：**每段首行缩进 2 个字符**（12pt 字号对应 `paragraph_format.first_line_indent = Pt(24)`），段间不空行，只用段落分隔。
- **一篇一页**，篇与篇之间插入分页符（`add_page_break()`）。
- 学生文章一般不超过 300 字，一页足够。**万一超了，就让这篇自然跨到下一页** —— 不压缩字号、不调行距、不删内容，超就超，不必纠结。**但下一篇仍然另起一页**，不要接着排。

## 六、每篇左上角的学生标识

学生的姓名和编号通常写在纸的左上角，都是**手写**的（卷子上不会有天然编号）。**先统计，再决定这一批要不要加标识**。统计按**篇**算，不按张算 —— 一篇跨了两页仍然只算一篇。

- 姓名：有手写姓名的文章 **≥ 50%** → 加姓名；**< 50%** → 不加。
- 编号：有手写数字编号（如 `1`、`12`）的文章 **≥ 50%** → 加编号；**< 50%** → 不加。

两个字段按下面的组合决定左上角写什么：

| 姓名 ≥50% | 编号 ≥50% | 左上角写 | 某篇漏写时 |
| --- | --- | --- | --- |
| 是 | 是 | `1-张三` | 漏编号 → `未编号-张三`；漏姓名 → `1-无名氏` |
| 是 | 否 | `张三` | `无名氏` |
| 否 | 是 | `1` | `未编号` |
| 否 | 否 | **什么都不写** | — |

- 只有一个字段时**不要加横杠**（不要写 `1-` 或 `-张三`）。
- 标识单独占一行，放在这篇正文的第一段之前，**左对齐**。
- 字号**小五（9pt）**、**加粗**、黑色。比正文小一号，让它是标签而不是正文。
- 编号里只要数字，不要 `No.`、`#`、`第` 之类的修饰。
- 一篇作文跨了两页时，标识只写在第一页顶部。

## 七、页面设置（硬性规定）

- **页边距**：上、下、左、右各 **2.2 cm**。
- **装订线**：**0 cm**。

## 八、末尾的「特别注意」（可选，没有就不写）

**这一段是可选的。** 没有需要提醒的地方就整段不写 —— 连「特别注意」这个标题、标题后面的空行都不要留，Word 到最后一篇正文结束为止。

有需要提醒时，才在 Word 最后加一段蓝字「特别注意」（格式见提示词），针对这份合辑具体写，不要写套话。**只写真正影响理解的问题，不要汇报「本次一切正常」「本次没有 XX 情况」这类话。** 该写的是：

- 哪一篇里有看不清、只能按上下文推断的词句，是哪几个词。
- 哪一篇可能是跨页拼合的，拼合的依据是什么（比如上一页末尾是半句话）。
- 有没有分不清「这是学生正文还是老师批注」的地方。
- 有没有判断不了「这是一篇的结尾还是下一篇的开头」的地方。
- 有没有该加学生标识却没加、或者统计边界模糊的篇目（统计结果本身不用汇报）。
- 有没有判断不了「这是不是手写作文」的图。
- 一条都没有 → 整段不写（见本节开头）。

## 九、其他可能遇到的情况（自行判断）

这一节没有硬规定，遇到时按最接近原意的办法处理：

- **图片模糊 / 反光 / 阴影**：整句都读不出来时，不要编一句像样的英文。按上下文能接上的词写，接不上就跳过这一句。
- **学生字迹潦草**：先按字母形状和上下文判断，实在分不清的按「常见单词」处理（比如 `thcir` 判断成 `their`），不要为了像而写成不存在的词。
- **标题行**：学生自己写的标题（如 `My Favourite Season`）算正文，照录，单独成段。
- **署名**：文章末尾学生自己写的名字（不是左上角的编号）算正文，照录。
- **页边涂鸦 / 草稿 / 划掉的整段**：不录。
- **一页里只有两三行字**：可能就是很短的一篇，不要因为「太短了不像作文」就并到上一篇里。
- **两篇之间没有明显分界**：看有没有新的开头（`Dear ...`、标题、署名）和末尾的句号，判断不了就按一篇处理。
